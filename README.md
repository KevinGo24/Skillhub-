    ## Arquitectura y Patrones de Diseño                                                                                                                                                                       
                                                                                                                                                                                                               
    El sistema sigue los principios de **Clean Architecture**:                                                                                                                                                 
                                                                                                                                                                                                               
    * **`SkillHub.Dominion`**: Entidades centrales del dominio (`Workshop`, `Enrollment`, `Instructor`, `Participant`), enumeraciones de dominio (`WorkshopStatus`, `EnrollmentStatus`, `UserRole`) y          
    excepciones de reglas de negocio. No tiene dependencias de librerías externas.                                                                                                                             
    * **`SkillHub.Application`**: Casos de uso, interfaces y contratos de servicio (`IWorkshopService`, `IEnrollmentService`, `IReportService`, `IAuthService`), DTOs y validación de reglas de negocio.       
    * **`SkillHub.infrastructure`**: Entity Framework Core 9 / Npgsql (PostgreSQL Code First), integración con ASP.NET Core Identity, generador de tokens JWT, generación de documentos con `QuestPDF`,        
    procesamiento de hojas de cálculo con `ClosedXML` e implementaciones de repositorios.                                                                                                                      
    * **`SkillHub.Api`**: Web API RESTful con endpoints protegidos mediante autenticación JWT Bearer, autorización basada en roles, middleware de manejo estructurado de errores y documentación interactiva   
    con Scalar.                                                                                                                                                                                                
    * **`SkillHub.Web`**: Portal web interactivo en ASP.NET Core MVC que consume la capa de aplicación directamente, con modo claro/oscuro, analíticas con Chart.js, alertas interactivas con SweetAlert2 y    
    flujos de trabajo completos para estudiantes e instructores.

    ## Configuración y Ejecución del Proyecto                                                                                                                                                                  
                                                                                                                                                                                                               
    ### Requisitos Previos                                                                                                                                                                                     
    * [.NET 10 SDK](https://dotnet.microsoft.com/download)                                                                                                                                                     
    * [PostgreSQL 15+](https://www.postgresql.org/) en ejecución en el puerto `5432`                                                                                                                           
                                                                                                                                                                                                               
    ### 1. Configuración de Base de Datos                                                                                                                                                                      
    Verifique y ajuste la cadena de conexión en `src/SkillHub.Api/appsettings.json` y `src/SkillHub.Web/appsettings.json`:                                                                                     
    ```json                                                                                                                                                                                                    
    "ConnectionStrings": {                                                                                                                                                                                     
      "DefaultConnection": "Host=localhost;Port=5432;Database=skillhub;Username=postgres;Password=TU_PASSWORD"                                                                                                 
    }                                                                                                                                                                                                          
                                                                                                                                                                                                               
  ### 2. Aplicar Migraciones y Carga Inicial de Datos (Seed)                                                                                                                                                   
                                                                                                                                                                                                               
  Ejecute las migraciones desde la raíz del repositorio:                                                                                                                                                       
                                                                                                                                                                                                               
    dotnet ef database update --project src/SkillHub.infrastructure --startup-project src/SkillHub.Api                                                                                                         
                                                                                                                                                                                                               
  Nota: Al iniciar por primera vez la API, se realiza la carga automática de instructores, participantes y talleres base desde SkillHub_Data.xlsx.                                                             
                                                                                                                                                                                                               
  ### 3. Ejecución de los Proyectos

    dotnet run --project src/SkillHub.Api                                                                                                                                                                      
                                                                                                                                                                                                               
  • URL Base de la API: http://localhost:5000                                                                                                                                                                  
  • Documentación Interactiva Scalar: http://localhost:5000/scalar/v1                                                                                                                                          
                                                                                                                                                                                                               
  #### Ejecución de la Aplicación Web MVC                                                                                                                                                                      
                                                                                                                                                                                                               
  En una terminal separada:                                                                                                                                                                                    
                                                                                                                                                                                                               
    dotnet run --project src/SkillHub.Web                                                                                                                                                                      
                                                                                                                                                                                                               
  • URL del Portal Web: http://localhost:5282

  ## Reglas de Negocio Implementadas                                                                                                                                                                           
                                                                                                                                                                                                               
  1. Control de Capacidad: No se permiten más inscripciones activas que el cupo máximo definido para el taller.                                                                                                
  2. Prevención de Duplicados: Un participante no puede inscribirse más de una vez en el mismo taller.                                                                                                         
  3. Cruce de Horarios: Se bloquea la matrícula si el participante ya tiene otro taller activo programado en la misma fecha y rango horario.                                                                   
  4. Fechas Futuras: Solo se permite crear e inscribirse en talleres con fecha posterior a la fecha y hora actual.                                                                                             
  5. Políticas de Cancelación:                                                                                                                                                                                 
      • Participantes: Pueden cancelar su inscripción voluntaria con un mínimo de 24 horas de anticipación al inicio del taller.                                                                               
      • Empleados/Instructores: Pueden cancelar una matrícula sin la restricción de las 24 horas, siempre que el taller no haya iniciado.                                                                      
      • Las cancelaciones liberan inmediatamente el cupo y registran auditoría (CancelledBy y CancelledAt).                                                                                                    
  6. Importación Masiva desde Excel: Procesamiento por lotes de inscripciones con validación y reporte de motivos de rechazo fila por fila.                                                                    
  7. Certificado Oficial en PDF: Generación de comprobante en alta calidad con folio único, fecha, datos del estudiante y firma del instructor.                                                                
  8. Métricas de Demanda: Gráficas en tiempo real con Chart.js y exportación a Excel con el listado de talleres más demandados.
